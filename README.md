# Garden Restaurant

Cafe ordering MVP for **Garden Restaurant** (Lazimpat, Kathmandu).

## Routes

- `/` — brand landing
- `/dashboard` — staff tables & today’s orders
- `/demo` — browse → confirm → sample payment (cash / card / QR)

Demo copy lives in `src/lib/demo-data.ts` (NPR).

## Develop

```bash
npm install
npm run dev
npm run build
```
